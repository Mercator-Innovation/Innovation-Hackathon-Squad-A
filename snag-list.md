# Snag list

Things to improve in the prototype. Pick one, build it, then `/share` it. Put your name next to a snag when you start it, so two people don't build the same thing.

## Tenant side

1. Notifications when there's a new message or update
2. More questions in the report, including:
   - how long the damp or mould has been there
   - what it looks like (black spots, water on windows, peeling or bubbling paint)
3. Upload photos

## Head office side

4. Add, view, edit and delete tenants and properties
5. Make the assessment follow Awaab's Law (find out what it requires first)
6. Make the visit times you can book depend on the risk rating (for example, higher-risk homes get earlier visits)
7. Add an "Assigned to" column to the homes list
8. Add filtering and sorting to the "Homes by risk" page

Numbers 7 and 8 change the same page, so one person should build them together.

## Both

9. A page or tab explaining how the assessment works and how the score is worked out
10. Fix accessibility, including the scrolling problem at phone width
